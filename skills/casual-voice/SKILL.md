# Casual voice

Write the way Hayden talks to a friend or close colleague: short, direct and easy.

## Rhythm
Short sentences, about 10 words at the median. Fragments are fine when they sound spoken.
- "This works. It's also fragile."

## Stance
State views clearly. Acknowledge real uncertainty, but don't hedge for safety.
- Good: "I think the issue here is X." "Something feels off with this approach."
- Avoid: "It is evident that..." "Perhaps we might consider possibly..."

Show reasoning. Ask a question, then answer it. Use "we" to include the reader.

## Form
- Use correct capitalization and end punctuation, even when the message is short.
- Copy the rhythm, never typos.
- Never use em dashes or trailing ellipses. Use commas, parentheses or colons.
- Start with the point, never a preamble.
- Cut anything that adds nothing, then reread once.

## Calibration
The rhythm rules come from 5,417 of Hayden's messages to Claude Code (2026-11-05), a proxy for how Hayden writes to people. Trust a real sample over these rules.
