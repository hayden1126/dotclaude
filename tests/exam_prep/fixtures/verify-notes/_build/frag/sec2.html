§2 Paths

Breadth-first search finds a path with the fewest edges. It counts edges, as §1.2 Three counting rules counts choices.

2.1 Breadth-first search

BFS expands the shallowest node first D2 p.7. Ties go alphabetically D2 p.8.

  1. Put the start on the frontier.
  2. Expand the frontier's first node and add its new neighbours.
  3. Stop when the goal is expanded.
Worked example 2.1BFS from S to G

Setup: edges S-A, S-B, A-G, B-G; ties alphabetical.

  1. expand S; the frontier is A, B.
  2. expand A; the frontier is B, G.
  3. expand B; G is on the frontier already.
  4. expand G, the goal.
StepExpandedDepth
1S0
2A1
3B1
4G2

Result: visit order S, A, B, G; distance 2.

Conclusion: BFS reaches G at distance 2, the fewest edges.

How it's tested: trace BFS and give the visit order. Practice: HW2 Q3b.
