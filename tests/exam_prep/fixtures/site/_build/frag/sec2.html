§2 Graphs

A graph is a set of nodes joined by edges. Recall from §1.2 the product rule: it bounds the number of edges.

2.1 Nodes and edges

An undirected graph on \(n\) nodes has at most \(\binom{n}{2}\) edges D2 #/4.

Conclusion: the bound is reached exactly when every pair is joined.

How it's tested: bound the edges of a described graph. Practice: HW1 Q2.

Not on Exam 1

Weighted graphs (D2 #/9) come after the exam's last slide. Kept for a later exam.

2.2 Walks

A walk follows edges from node to node; its length is the number of edges it uses D2 #/6.

Walks in code

An adjacency list stores each node's neighbours, and a walk is valid when every step follows one W1 §3.1.

adj = {"A": ["B", "C"], "B": ["A", "C"], "C": ["A", "B"]}
def is_walk(path):  # A <-> B & B <-> C is a walk of length 2
    return all(b in adj[a] for a, b in zip(path, path[1:]))
Background

Only the slides prove that a shortest walk never repeats a node (D2 #/7); no practice question asks for it.

How it's tested: trace a walk and give its length. Practice: HW1 Q3.

2.3 Must know

  • Edge bound: \(\binom{n}{2}\), reached by the complete graph (§2.1)
  • Walk length: the number of edges it uses (§2.2)
