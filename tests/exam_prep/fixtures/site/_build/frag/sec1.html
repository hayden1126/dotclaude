§1 Counting

Counting asks how many objects fit a description. It builds on nothing earlier, and §2 Graphs uses it to count edges.

1.1 Sums of a range

The sum of the first n integers is \(\frac{n(n+1)}{2}\) D1 p.4. Pairing the first term with the last gives

\[ \sum_{i=1}^{n} i = \frac{n(n+1)}{2}. \]
Definition

A range is every integer from a to b, inclusive D1 p.3.

To sum a range:

  1. Count its terms: \(b - a + 1\).
  2. Add the first and the last term.
  3. Multiply the two and halve the product.
Worked example 1.1Summing 3 to 7

Setup: the range 3 to 7.

  1. 5 terms.
  2. \(3 + 7 = 10\).
  3. \(5 \times 10 / 2 = 25\).

Result: 25.

Conclusion: the pairing rule needs only the count and the two ends.

How it's tested: compute a sum and show the pairing. Practice: HW1 Q1a.

1.2 Three counting rules

  • a) Product: independent choices multiply D1 p.6.
  • b) Sum: disjoint cases add.
  • c) Bijection: count an easier set that matches one to one.
Key rule

Choose the rule by the shape of the description: "and" multiplies (rule a), "or" adds (rule b).

DescriptionRuleCount
a 3-letter code over 26 lettersproduct\(26^3 = 17576\)
a code of 1 or 2 digitssum\(10 + 100 = 110\)
Pitfall

Adding cases that overlap counts their overlap twice; the sum rule needs disjoint cases.
