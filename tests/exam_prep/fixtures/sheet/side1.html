Graph basicsL1

Counting

Sum of degrees = 2|E|, so the number of odd-degree vertices is even.

Simple graph: |E| ≤ n(n−1)/2. A tree on n vertices has n−1 edges.

Adjacency matrix: n2 space, O(1) edge test. Lists: n+m space, O(deg) test.

Connectivity

Connected: a path between every pair. Components partition V.

Trap: a directed graph is strongly connected only if every u reaches every v and back.

BFSL1

BFS(s): d[s]=0; Q=[s]
while Q: u=pop front
  for v in adj(u) sorted:
    if v unseen: d[v]=d[u]+1; push v

Layer k holds exactly the vertices at distance k from s.

Trace write the queue after each pop; mark a vertex seen when it is pushed, not popped.

Dijkstra

d[s]=0, others ∞; PQ = all
pop min u; for each edge (u,v,w):
  if d[u]+w < d[v]: d[v]=d[u]+w

Once popped, d[u] is final (weights ≥ 0).
