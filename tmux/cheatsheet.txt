
  tmux keys   (q to close)

  MENUS
    C-b Enter    action menu (do things)
    C-b ?        all keys (raw tmux list)

  TAB BAR  (rows by project: a repo with lanes, then the rest)
    tap a tab    switch to it
    tap again    its menu: Star / Shelve / Shelf… / Replies before pass /
                 Move… / Name row… / Rename / Windows…
    tap +N       the windows the bar has no room for
    S-arrows     the tab left / right / above / below, as drawn (no prefix)

  ARRANGE TABS  (kept across /clear and a restore)
    drag a tab   onto a tab: before or after it; onto a row's edge: first or last
    C-b S-arrows carry this tab left / right, or up / down a row (repeats)
    Move…        ◀ ▶ ▲ ▼, New row (a row of its own below; a shared tab's sits just
                 above the shared rows), Name row…, Auto place (back where the bar
                 puts it); stays open for the next step (phone), but not after
                 Name row…
    Name row…    name a custom row (empty clears it)
    C-b Enter    Move… / Reset bar (every tab back where the bar puts it)

  WINDOWS  (one per repo)
    C-b c        new window (keeps dir)
    C-b ,        rename window
    C-b 1..9     jump to window N
    C-b n / p    next / prev window
    C-b w        pick from a list

  PANES  (splits)
    C-b |        split right
    C-b -        split down
    C-b <arrow>  move between panes
    C-b z        zoom pane / back

  SCROLL & COPY
    wheel or C-b [   enter, q exits
    drag to select   -> clipboard

  SHELF  (Claude chats, kept after the tab closes)
    right-click a tab   Star (★, a bookmark) / Shelve (save + close) / Shelf…
                        (or tap the tab you are on)
    C-b S        the shelf: reopen a starred or shelved chat
    C-b Enter    Star / Shelve / Shelf… too (no Shift)

  AFTER /pass
    C-b Up       the replies before the pass (popup; also in the menus)

  SESSION
    C-b d        detach (keeps running)
    C-b s        list / switch sessions

  CONFIG
    C-b r        reload ~/.tmux.conf
